📡 API Reference

          Open Swagger UI ↗
        


        


          

            

              POST
              /classify
              Classify a single HTTP request
            

            

              
Request Body

              
{
  "raw_request": "GET /search?q=1+UNION+SELECT+null,password-- HTTP/1.1\r\nHost: example.com\r\n\r\n",
  "explain": true
}

              
Response

              
{
  "label": "sqli",
  "label_display": "SQL Injection",
  "confidence": 0.9823,
  "action": "BLOCK",
  "threat_level": "HIGH",
  "all_scores": {"benign": 0.01, "sqli": 0.98, "xss": 0.003, ...},
  "saliency": {"UNION": 0.94, "SELECT": 0.91, "password": 0.87},
  "latency_ms": 12.4,
  "request_id": "a1b2c3d4"
}

            

          


          

            

              POST
              /batch
              Classify up to 100 requests at once
            

            

              
{"requests": ["GET /path?q=payload HTTP/1.1...", ...], "explain": false}

            

          


          

            

              GET
              /stats
              Aggregated statistics (total, blocked, attack breakdown)
            

          


          

            

              GET
              /history?page=1&page_size=50&action=BLOCK
              Paginated request history with optional action filter
            

          


          

            

              GET
              /health
              System health check — model loaded status, device, demo mode
            

          


          

            
Integration Examples

            
Python (direct pipeline)

            
from src.pipeline.transwaf import TransWAF

waf = TransWAF(model_path="models/transwaf_best")
result = waf.classify(raw_http_request)

if result["action"] == "BLOCK":
    raise SecurityError(result["label_display"])


            
cURL

            
curl -X POST http://localhost:8000/classify \
  -H "Content-Type: application/json" \
  -d '{"raw_request": "GET /?q=test HTTP/1.1\r\nHost: x.com\r\n\r\n"}'
